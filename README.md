# ✨ Craft CV

> **Create a professional resume that represents your skills, experience, and career journey.**

Craft CV is a modern, user-friendly resume builder designed to help users create professional and visually appealing resumes without struggling with complicated formatting or design tools.

🌐 **Live Demo:** https://craftcv-studio.vercel.app/

---

## 🚀 Overview

Creating a professional resume from scratch can be time-consuming. Formatting, choosing the right layout, maintaining consistency, and making the resume ATS-friendly can all become frustrating.

**Craft CV** simplifies this process by providing an intuitive interface where users can create, customize, preview, and download their resumes.

The goal is simple:

> **Your career deserves a better presentation.**

## ⚙️ Getting Started

Follow these steps to run Craft CV locally.

### 1. Clone the repository

```bash
git clone https://github.com/Ankit-5515/YOUR-REPOSITORY.git
```

### 2. Navigate into the project

```bash
cd craft-cv
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 🏭 Production Build

To create a production build:

```bash
npm run build
```

Then start the production server:

```bash
npm start
```

 Production Website

## 🔐 Environment Variables

If environment variables are required in the project, create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=your_api_url
```

Never commit sensitive information such as:

```text
API keys
Database passwords
JWT secrets
Private tokens
Authentication secrets
```

Make sure `.env.local` is included in `.gitignore`.
